# Исполнение плана закупок для ERP

`GET /api/procurement/plans/{id}/execution` рассчитывает показатели в текущем tenant и компании. Сумма заказанных строк показывает стоимость заказанного количества; сумма приёмки рассчитывается по принятому количеству и цене строки. Данные пересчитываются при каждом запросе.

Заказы сопоставляются по заявкам планов потребности из указанного цикла и по явно связанным с планом кампаниям и процедурам. Используются связанные заявки, заказы, договоры и RFQ. Для плана без цикла и без таких связей ответ содержит предупреждение и не включает заказы компании автоматически. Дополнительно применяются период плана, группа материала и статья бюджета, если они установлены.

Заказы в других валютах приводятся к валюте плана с использованием курса заказа и справочника курсов. При отсутствии требуемого курса строка исключается с предупреждением. Показатели следует сверить с правилами учёта предприятия перед использованием для финансового закрытия периода.
